# AI-game

🎲 **4 人吹牛骰子遊戲 (Liar's Dice)**

基於純前端技術（HTML5 / CSS3 / JavaScript）構建的 4 人吹牛骰子對戰網頁遊戲。

## 🌟 遊戲特色

- **4 人極限對決**：玩家 1（你）vs 3 位 AI 玩家（玩家 2、玩家 3、玩家 4）。
- **AI 智能決策**：AI 依據場上存活骰數、二項分佈期望值與心理博弈進行加注或抓吹牛。
- **即時視覺回饋**：
  - 專屬玩家色彩與思考中狀態提示
  - 開牌高亮統計與點數即時計算
  - 淘汰機制與勝負即時結算面板
- **即開即玩**：無需安裝任何套件，開啟 `liars_dice.html` 或 `index.html` 即可遊玩。

## 🎮 玩法說明

1. **每人起始手牌**：5 顆骰子（4 人共 20 顆骰子）。
2. **叫牌規則**：
   - 順時針輪流行動。
   - 每次叫牌必須增加數量，或在相同數量下增加點數（例如：`3 個 2` ➔ `3 個 4` ➔ `4 個 2`）。
   - **1 點為萬用點數**，可充當任何點數；但一旦有玩家叫過 1 點，1 點即失去萬用功能。
3. **抓吹牛 (Call Liar)**：
   - 輪到的玩家若懷疑上一位玩家吹牛，可點擊「抓！」。
   - 開盅揭曉場上所有骰子，若目標點數總數 $\ge$ 叫牌數，叫牌成立，抓人者失去 1 顆骰子；反之，叫牌者失去 1 顆骰子。
4. **勝負判定**：
   - 骰子輸光者淘汰出局。
   - 堅持到最後的唯一玩家贏得冠軍！
